Ollama is an open-source tool that allows users to run large language models locally on their own computers, without requiring cloud services or API keys. It was first released in 2023 and is developed by the Ollama team.

Ollama supports a wide range of open-source models including Llama 3, Mistral, Phi-3, Gemma, Qwen 2, CodeLlama, and many others. These models can be downloaded from the Ollama model library at ollama.com/library.

To install Ollama on macOS, download the installer from ollama.com and place the Ollama application in your Applications folder. On Linux, you can install it by running: curl -fsSL https://ollama.com/install.sh | sh. On Windows, download and run the installer from the official website.

Once installed, you can pull a model with the command: ollama pull llama3.2. To run an interactive chat session in the terminal, use: ollama run llama3.2.

Ollama exposes a REST API on localhost port 11434. The main endpoints are /api/generate for single-turn generation and /api/chat for multi-turn conversation. An official Python library called ollama is available and can be installed via pip.

The Python library provides two main functions: ollama.generate() for single completions and ollama.chat() for conversational use. Both support streaming responses by passing stream=True. The ollama.embeddings() function generates vector embeddings for text, which is useful for building RAG (Retrieval-Augmented Generation) pipelines.

Models in Ollama are stored in a local directory and are downloaded once. They can be listed with ollama list and removed with ollama rm. The amount of RAM required depends on the model size: small 3B models typically need around 4 GB, 7B models need around 8 GB, and 13B models need around 16 GB.
