## Script

**Host:**
Welcome to Module 1! This is the very first program every developer writes: Hello, World.

Open VS Code and create a new file called `hello.py`. Type:

```python
print("Hello, World!")
```

Open the terminal with **Ctrl+`** and run it:

```
python hello.py
```

You should see `Hello, World!` in the terminal. That's it — you just ran your first Python program!

`print()` is a **built-in function** — a command Python understands out of the box. Whatever you put between the parentheses gets displayed on screen.

You can print multiple things at once:

```python
print("Hello", "from", "Python")
print("The answer is", 42)
```

And you can use `print()` to leave a blank line:

```python
print("Line one")
print()
print("Line three — there's a gap above me!")
```

**Host:**
Simple, but powerful. In the next module we'll store values in variables so our programs can remember things.
